## RD Station

### O que está instalado hoje

- Código de monitoramento do RD em todas as páginas — Loader 6f97e3ea-8262-4628-9b3d-c60836019ba6 servido pela CloudFront.
- RD Tracker: registra as páginas visitadas — Guarda um token de sessão (rdtracker:token). O histórico é ligado ao lead quando ele converte.
- Traffic Source: cookie __trf.src — Guarda a origem da visita (orgânico, pago, social, UTM) para atribuir o lead.
- RD Pop-ups: script carregado — Consulta popups.rdstation.com.br; nenhum pop-up apareceu durante a visita.
- RD Cookie Control disponível, mas o banner usado é o CookieYes **[VERIFICAR]** — O rastreamento do RD deveria respeitar a escolha feita no banner.

### O que NÃO foi encontrado

- Formulário ou landing page nativa do RD no site **[PROBLEMA]**
- Módulo de captura de formulários externos **[PROBLEMA]** — O loader do RD não carrega o módulo de formulários. Forte indício de que o formulário MetForm não chega ao RD.
- Plugin oficial “Integração RD Station” no WordPress **[PROBLEMA]**
- Integração por webhook ou API **[VERIFICAR]** — Pode existir no MetForm (webhook), no Code Snippets ou via Zapier/Make. Só dá para confirmar com acesso aos painéis.

### Como o RD Station funciona

- RD Station Marketing
  - Código de monitoramento — Rastreia visitantes anônimos. Quando alguém preenche um formulário, o histórico de navegação passa para o lead.
  - Conversão — Cada preenchimento de formulário, landing page, pop-up ou envio por API. Cada uma leva um “identificador” que diz de onde o lead veio.
  - Base de leads e segmentações — Listas por produto de interesse, setor, cidade ou estágio do funil.
  - Lead scoring — Nota de perfil (cargo, empresa, setor) + nota de interesse (páginas vistas, e-mails abertos, conversões).
  - Automação de marketing — Fluxos disparados por conversão ou segmentação. Ex.: baixou o catálogo → e-mails sobre tubos → convite para orçamento.
  - E-mail marketing, landing pages e pop-ups
  - Funil: visitante → lead → lead qualificado → oportunidade → cliente
- RD Station CRM
  - Funil de vendas com negociações, tarefas e histórico
  - Recebe o lead marcado como oportunidade no Marketing
  - A MC usa o CRM do RD? **[VERIFICAR]**
- Formas de ligar o site ao RD
  - 1. Integração de formulários pelo código de monitoramento — <https://ajuda.rdstation.com/s/article/Integra%C3%A7%C3%A3o-de-Formul%C3%A1rios-via-C%C3%B3digo-de-Monitoramento?language=pt_BR> — O RD passa a capturar os formulários HTML do site. Precisa ser ativada na conta do RD e testada (formulários montados em JavaScript podem falhar).
  - 2. Plugin oficial “Integração RD Station” para WordPress — <https://wordpress.org/plugins/integracao-rd-station/>
  - 3. API de conversões do RD — O formulário/servidor envia o lead direto ao RD (webhook ou código no tema). Mais confiável e aceita campos personalizados.
  - 4. Formulário ou landing page criados no próprio RD e incorporados
  - 5. Conectores: Zapier, Make, n8n
